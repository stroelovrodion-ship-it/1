# 🎮 Маги Нового Мира - Text RPG

## 📋 Описание

Текстовая RPG с глубокой системой конструктора магии, основанной на тегах и модульной архитектуре.

---

## ✨ Основные возможности

### 🔮 Конструктор магии

#### Система слотов
- **2 слота** на старте
- **Новый слот каждые 5 уровней** (максимум 7 слотов на 25 уровне)
- Каждый слот можно **переименовать** (кнопка ✎)
- Каждый слот имеет **уровень мастерства** (1-7)

#### Режимы конструирования

**✨ На себя:**
- Руны времени (макс 2)
- Руны эффекта/уникальные (макс 1)
- ОЧСМ (очки силы магии) ограничивают сложность

**⚔️ На врага:**
- Выбор стихии (огонь, вода, земля, воздух, свет, тьма)
- Траектория (прямая, дуга, самонаведение, рассеивание, пронзающая)
- Форма (снаряд, стрела, сфера, волна, луч, нова)
- Дополнительный эффект из свитков

#### Уровни мастерства
Каждое заклинание прокачивается через использование:
- **Ур. 1 (Новичок):** 0 кастов
- **Ур. 2 (Ученик):** 10 кастов (+10% урона, -5% MP)
- **Ур. 3 (Адепт):** 25 кастов (+20% урона, -10% MP, +5% крит)
- **Ур. 4 (Мастер):** 50 кастов (+35% урона, -15% MP, +10% крит)
- **Ур. 5 (Виртуоз):** 100 кастов (+50% урона, -20% MP, +15% крит)
- **Ур. 6 (Магистр):** 200 кастов (+75% урона, -25% MP, +20% крит, крит x3)
- **Ур. 7 (Архимаг):** 500 кастов (+100% урона, -30% MP, +25% крит, крит x4)

---

### ⚔️ Боевая система

#### Интерфейс боя
- **Одна кнопка "Магия"** с раскрывающимся списком всех заклинаний
- Отображается уровень мастерства (★) рядом с названием
- Выбор части тела врага для атаки

#### Уникальные эффекты
- **Эффекты не стакаются** - если горение уже активно, повторное применение невозможно
- Система `activeDebuffs` отслеживает активные эффекты по элементам
- Визуальное предупреждение: "⚠️ Горение уже активно!"

#### Части тела врага
Каждый враг имеет части тела с уникальными слабостями/сопротивлениями:
- Голова, Торс, Руки, Ноги, Крылья, Хвост
- Изучаются через атаки разными стихиями
- Слабости: x1.5 урона
- Сопротивления: x0.5 урона

---

### 📚 Система прогрессии

#### Уровни персонажа
- **Ур. 1-4:** 2 слота магии
- **Ур. 5-9:** 3 слота (+1 ко всем стихиям)
- **Ур. 10-14:** 4 слота (+2 ко всем стихиям)
- **Ур. 15-19:** 5 слотов (+3 ко всем стихиям, +10 HP, +5 MP)
- **Ур. 20-24:** 6 слотов (+5 ко всем стихиям, +20 HP, +10 MP)
- **Ур. 25+:** 7 слотов (+7 ко всем стихиям, +30 HP, +15 MP)

#### Свитки
- **Формы:** снаряд, стрела, сфера, волна, луч, нова
- **Эффекты:** горение, обморожение, шок, отравление, ослепление, проклятие
- Каждый свиток можно найти в локациях или получить с врагов

## 📁 SQL файлы

### `sql/magic.sql`
Содержит полную базу данных магии:
- **runes** - 27 рун (время, эффект, уникальные)
- **trajectories** - 7 траекторий
- **spell_forms** - 9 форм заклинаний
- **spell_form_levels** - 5 уровней для каждой формы (45 записей)
- **scroll_effects** - 18 эффектов из свитков
- **synergies** - 12 синергий (комбинации элемент+форма)
- **spell_mastery** - 7 уровней мастерства

### `sql/enemies.sql`
Полная база врагов:
- **enemies** - 35+ уникальных врагов
  - Руины: скелет, скелет-лучник, руинный голем, призрак рыцаря, страж склепа
  - Проклятый лес: теневой волк, лесной паук, лесной призрак, древень, ведьма чащи, альфа-волк
  - Кристаллические пустоши: кристальный паук, элементаль воздуха, кристальный голем, призматический змей, штормовая гарпия
  - Подземелье: пещерная летучая мышь, тёмный слайм, гигантская крыса, ползун тоннелей, костяной лорд, лавовый червь
  - Боссы: пепельный король, кристальная королева, мать леса, лорд пустоты
- **enemy_body_parts** - части тела для каждого врага со слабостями/сопротивлениями
- **enemy_loot** - таблица лута с шансами выпадения

### `sql/items_resources_bonuses.sql`
Всё остальное:
- **items** - 30+ предметов (оружие, броня, аксессуары, расходники, материалы)
- **scrolls** - 17 свитков (формы и эффекты)
- **magic_bonuses** - бонусы за уровни мастерства
- **level_bonuses** - бонусы за уровни персонажа
- **craft_recipes** - 12 рецептов крафта

### `sql/locations.sql`
Полная база локаций:
- **locations** - 16 локаций разных типов:
  - 🏰 Города (3): Пепельная Гавань, Кристальный Шпиль, Ржавый Порт
  - ⛺ Лагеря (3): Лагерь кочевников, Лагерь торговцев, Лагерь охотников
  - 🏛️ Подземелья (3): Руины, Подземные тоннели, Забытые руины
  - ⚔️ Дикие местности (2): Кристаллические пустоши, Проклятый лес
  - 🌍 Материки (3): Северный, Южный, Восточный
  - ✨ Особые (2): Древняя библиотека, Пик Дракона
- **location_connections** - связи между локациями с временем путешествия
- **location_resources** - ресурсы с шансами появления
- **location_enemies** - враги с весами спавна
- **location_events** - события локаций (отдых, торговля, обучение, квесты, опасности)

## 🎯 Геймплей

### Начало игры
1. Создай первое заклинание в конструкторе
2. Переименуй его (кнопка ✎)
3. Иди в бой через "Локации" или "Путешествие"
4. Выбери часть тела врага
5. Нажми "Магия" → выбери заклинание из списка

### Прокачка
- Используй заклинания → растёт мастерство
- Побеждай врагов → получаешь опыт и золото
- Достигай новых уровней → открывай слоты магии
- Находи свитки → изучай новые формы и эффекты
- Регенерация HP/MP работает автоматически в бою (+X за ход)

### Типы локаций
- 🏰 **Города** - безопасные зоны с магазинами и тавернами (отдых: 5 золота)
- ⛺ **Лагеря** - временные поселения с базовыми услугами (отдых: 2 золота)
- 🏛️ **Подземелья** - опасные зоны с сильными врагами и лутом
- ⚔️ **Дикие местности** - открытые территории с монстрами и ресурсами
- 🌍 **Материки** - огромные территории с уникальными врагами (уровень 7-10)
- ✨ **Особые локации** - уникальные места с редкими возможностями

### Карта мира
- Интерактивная карта с иконками для каждого типа локации
- Легенда в правом верхнем углу
- Линии связей между локациями (подсвечиваются при выборе)
- Детальная информация при клике на локацию:
  - Тип и описание
  - Уровень опасности (1-10)
  - Связи с другими локациями
  - Список врагов
  - Доступные ресурсы
  - Кнопка путешествия

### Тактика
- Изучай слабости врагов через атаки разными стихиями
- Комбинируй элементы и формы для синергий
- Не применяй эффекты повторно - они не стакаются
- Переименовывай заклинания для удобства
- Отдыхай в лагерях для быстрого восстановления (дешевле городов)
- Исследуй материки для получения редких ресурсов и опыта

## 🛠️ Технические детали

### Архитектура
- **React + TypeScript** - типобезопасность
- **Модульная система тегов** - гибкость и расширяемость
- **SQL-first подход** - все данные в SQL файлах
- **Компонентный UI** - переиспользуемые компоненты

### Ключевые файлы
- `src/types/tags.ts` - все типы и интерфейсы
- `src/engine/gameEngine.ts` - игровая логика
- `src/data/*.ts` - данные (руны, враги, предметы)
- `src/App.tsx` - основной компонент
- `sql/*.sql` - база данных

### Особенности реализации
- **Уникальные дебаффы:** `activeDebuffs` в `EnemyInstance`
- **Прогрессия мастерства:** `totalCasts` и `masteryLevel` в `SpellSlot`
- **Динамические слоты:** `getMaxSlots(level)` вычисляет доступные слоты
- **Переименование:** `customName` в `SpellSlot`
- **Раскрывающийся список:** `showSpellList` state в UI
- **Регенерация:** `hpRegen` и `mpRegen` в `HeroStats` (автоматически в бою)
- **Типы локаций:** 6 типов (city, camp, dungeon, wild, continent, special)
- **Интерактивная карта:** SVG линии связей, иконки типов, легенда
