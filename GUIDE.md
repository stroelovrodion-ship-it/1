# 📖 Руководство по запуску и сохранению

## 🚀 Запуск игры

### Способ 1: Автоматический запуск (рекомендуется)

#### Windows
1. Найдите файл `launch.bat` в корневой папке проекта
2. Двойной клик по файлу
3. Дождитесь автоматического открытия браузера

#### Linux/Mac
1. Откройте терминал в папке проекта
2. Выполните команду:
   ```bash
   chmod +x launch.sh  # Только первый раз
   ./launch.sh
   ```
3. Дождитесь автоматического открытия браузера

### Способ 2: Ручной запуск

```bash
# 1. Установите зависимости (только первый раз)
npm install

# 2. Запустите игру в режиме разработки
npm run dev

# 3. Откройте браузер по адресу:
# http://localhost:5173
```

### Способ 3: Сборка для продакшена

```bash
# 1. Соберите проект
npm run build

# 2. Файлы будут в папке dist/
# 3. Разместите dist/ на веб-сервере
```

## 💾 Система сохранения

### Главное меню

При запуске игры вы видите главное меню:

```
╔═══════════════════════════════════════╗
║        МАГИ НОВОГО МИРА              ║
║                                       ║
║   🎮 НОВАЯ ИГРА                       ║
║   💾 ЗАГРУЗИТЬ ИГРУ                   ║
║                                       ║
║   Последнее сохранение:               ║
║   📅 15.01.2024 14:30                ║
║   ⭐ Уровень: 5                       ║
║   📍 Кристальный Шпиль               ║
╚═══════════════════════════════════════╝
```

**Кнопки:**
- **🎮 НОВАЯ ИГРА** - начать новое приключение с нуля
- **💾 ЗАГРУЗИТЬ ИГРА** - продолжить сохранённую игру (появляется только если есть сохранение)

### Сохранение в игре

В нижней части игрового интерфейса есть две кнопки:

1. **💾 Сохранить** - сохраняет текущий прогресс
   - Появляется сообщение "✅ Игра сохранена!"
   - Сохранение происходит мгновенно
   - Можно сохраняться в любой момент

2. **🚪 В меню** - возвращает в главное меню
   - Текущий прогресс НЕ сохраняется автоматически
   - Не забудьте сохраниться перед выходом!

### Что сохраняется

При сохранении фиксируется:

#### Персонаж
- ✅ Имя и уровень
- ✅ Опыт и золото
- ✅ Все статы (сила, ловкость, интеллект, удача)
- ✅ Сила стихий (огонь, вода, земля, воздух, свет, тьма)
- ✅ HP и MP (текущие и максимальные)
- ✅ Регенерация HP/MP
- ✅ ОЧСМ (очки силы магии)

#### Инвентарь
- ✅ Вся экипировка (9 слотов)
- ✅ Все предметы в сумке
- ✅ Количество каждого предмета

#### Магия
- ✅ Все слоты заклинаний (до 7)
- ✅ Руны в слотах "на себя"
- ✅ Конструкторы в слотах "на врага"
- ✅ Уровни мастерства заклинаний
- ✅ Количество кастов
- ✅ Пользовательские имена заклинаний

#### Прогресс
- ✅ Текущая локация
- ✅ Бестиарий (изученные враги)
- ✅ Изученные части тела врагов
- ✅ Лог событий
- ✅ Время игры

### Где хранятся сохранения

- Сохранения хранятся в **localStorage** браузера
- Ключ: `magi_novogo_mira_save`
- Поддерживается только **одно сохранение** (последнее)
- Данные сохраняются между сессиями
- Очистка кэша браузера удалит сохранения

### Управление сохранениями

#### Через консоль браузера (F12)

```javascript
// Проверить наличие сохранения
localStorage.getItem('magi_novogo_mira_save')

// Удалить сохранение
localStorage.removeItem('magi_novogo_mira_save')

// Экспорт сохранения (копирование в буфер обмена)
copy(localStorage.getItem('magi_novogo_mira_save'))

// Импорт сохранения (вставить JSON)
localStorage.setItem('magi_novogo_mira_save', 'JSON_STRING')
```

#### Резервное копирование

1. Откройте игру в браузере
2. Нажмите F12 (консоль разработчика)
3. Перейдите во вкладку "Application" (Приложение)
4. Найдите "Local Storage" → ваш домен
5. Найдите ключ `magi_novogo_mira_save`
6. Скопируйте значение
7. Сохраните в текстовый файл

#### Восстановление из резервной копии

1. Откройте консоль браузера (F12)
2. Выполните:
   ```javascript
   localStorage.setItem('magi_novogo_mira_save', 'ВАШ_JSON')
   ```
3. Перезагрузите страницу
4. В главном меню нажмите "💾 ЗАГРУЗИТЬ ИГРУ"

## 🔧 Решение проблем

### Игра не запускается

**Проблема:** `launch.bat` или `launch.sh` не работает

**Решение:**
1. Убедитесь, что Node.js установлен:
   ```bash
   node --version
   ```
2. Если не установлен, скачайте с https://nodejs.org/
3. Установите зависимости вручную:
   ```bash
   npm install
   ```
4. Запустите вручную:
   ```bash
   npm run dev
   ```

### Сохранение не работает

**Проблема:** Кнопка "💾 Сохранить" не работает

**Решение:**
1. Проверьте, что localStorage не отключен
2. Очистите кэш браузера
3. Попробуйте другой браузер
4. Проверьте консоль браузера (F12) на ошибки

### Сохранение пропало

**Проблема:** Сохранение исчезло после очистки кэша

**Решение:**
1. К сожалению, восстановление невозможно
2. localStorage очищается при:
   - Очистке кэша браузера
   - Использовании режима инкогнито
   - Удалении данных сайта
3. Рекомендуется делать резервные копии (см. выше)

### Игра тормозит

**Проблема:** Интерфейс работает медленно

**Решение:**
1. Закройте другие вкладки браузера
2. Отключите расширения браузера
3. Попробуйте другой браузер
4. Проверьте системные требования:
   - Минимум 2 GB RAM
   - Современный браузер (Chrome, Firefox, Edge)

## 📊 Системные требования

### Минимальные
- **ОС:** Windows 7+, macOS 10.12+, Linux
- **RAM:** 2 GB
- **Браузер:** Chrome 90+, Firefox 88+, Edge 90+
- **Node.js:** 18.x или выше (для запуска)

### Рекомендуемые
- **ОС:** Windows 10+, macOS 12+, Linux
- **RAM:** 4 GB
- **Браузер:** Последняя версия Chrome/Firefox
- **Node.js:** 20.x LTS
